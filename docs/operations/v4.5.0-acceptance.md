## Product path

The release starts an unknown Source journey with Engine-owned 项目分类分析. It validates the user's 业务分类方案, builds an immutable taxonomy-blind and LLM-free Source concept hypothesis, combines deterministic retrieval with one bounded advisory LLM analysis, and returns a finite classification result for each 业务领域 and 产品或系统类型 axis.

`SourceDescriptor/v1` covers local files, local directories, local Git repositories, GitHub repositories, controlled fixtures, and exact ordered attachment sets. Source acquisition is static and non-executing. GitHub Sources are commit-pinned, credentials remain operator-managed, and unsupported submodules or Git LFS fail closed.

Only a complete classification match plus a separate explicit human choice creates the immutable handoff into the retained v4.4 Harness lifecycle: Eligibility, professional Source-to-Harness reasoning, Catalog comparison, Proposal Review, explicit approval, separate publication authorization, Catalog validation, recovery, and safe close.
