# v4.1.1 Acceptance

This page defines the acceptance surface for the npm OIDC Trusted Publishing repair. It does not reopen or change the v4.1 controlled comparative-evidence runtime. Passing implementation acceptance does not authorize commit, push, tag, GitHub Release, npm, GHCR, or deployment.

## Deterministic Commands

```bash
npm run roadmap:check
node --test tests/npm-distribution.test.mjs
node --test tests/v4.1.test.mjs
npm run v3:check
npm run digital-expert:check
npm run verify:architecture
npm run check
npm run package:verify
npm run package:smoke
npm run roadmap:release -- 4.1.1 --json
npm run release:artifact
npm run verify:release-artifact
npm run docs:links
git diff --check
```

## Acceptance Matrix

| Criterion | Required evidence |
|---|---|
| OIDC-only setup | Parsed workflow proves `contents: read`, `id-token: write`, protected `npm` Environment, and no setup-node `registry-url` or `always-auth`. |
| Token boundary | Executable negative test proves an explicitly supplied `NODE_AUTH_TOKEN` fails closed without exposing the token; the workflow has no npm secret or token fallback. |
| Publication closure | Exact tag/package/dist-tag binding, provenance, integrity, signatures, attestation, audit, clean installation, bootstrap, and `npx` assertions remain present. |
| Runtime compatibility | Complete v4.1 controlled comparison, calibration, v3, Digital Expert, architecture, and repository checks pass unchanged. |
| Installed package | The 4.1.1 allowlist and clean tarball smoke use installed modules and stdio MCP without resolving through the source checkout. |
| Release candidate | Exact 4.1.1 Roadmap release gate, release artifacts, checksums, documentation links, and diff checks pass with no unrelated product change. |

## Authority Interpretation

Passing this matrix proves the local source candidate and publication contract. It does not prove that `@evopilot/harness@4.1.1` exists in npm. Public availability requires a separately authorized Release, a successful GitHub workflow, and an independent Registry readback.
