# EvoPilot Harness 4.0.1

v4.0.1 is the first completed Agent-native EvoPilot Harness release. It supersedes the v4.0.0 source tag, whose GitHub Actions workflow stopped before GitHub Release and GHCR publication.

## Added

- Portable Agent-neutral Digital Expert Core with deterministic Codex, WorkBuddy, Claude Code, MCP, and Generic Adapters.
- Local stdio MCP Harness Operation Server with version negotiation, typed tools, resources, health reporting, graceful shutdown, and no default network listener.
- Persistent `AgentOperationSession` with digest-bound Plans, Proposal Review, approval, separate publication authorization, interruption recovery, cross-Agent resume, and safe close.
- Direct structured Engine adapter and independent Generic Agent Host conformance coverage.

## Fixed

- Resolve `lsof` through the runner `PATH` when validating that the stdio MCP process opens no TCP listener.
- Fail with an explicit diagnostic if network-listener inspection cannot execute instead of dereferencing missing command output.
- Accept package patch versions covered by a declared Roadmap release line, matching the existing `roadmap:release` contract.

## Preserved

- Engine authority for Harness reasoning and Proposal Review verdicts.
- Separate digest-bound human approval and publication decisions.
- Static Evidence Source ingestion with no source-project command execution.
- External Workspace confinement and secret-free Session persistence.
- v3 Harness assets, Proposals, Catalog, Registry, feedback packages, EvaluationPack compatibility, and JSON CLI automation.

## Excluded

- Remote or multi-tenant MCP.
- Embedded conversational model or general Agent runtime.
- Automatic approval, publication, model configuration, or source execution.
- EvoPilot Goal Loop behavior.
- v4.1 comparative evidence and v4.2 professional asset learning.

## Validation

- Roadmap intent, static contract, and `4.0.1` release gates.
- Digital Expert generated-artifact and scenario-conformance checks.
- Architecture boundary verification.
- Complete repository test and v3 compatibility suites.
- Local source archive, SPDX SBOM, provenance, and checksum verification.
- GitHub Linux CI and tag-triggered Release Artifacts workflows.
