# evopilot-harness 4.2.4

> Status: candidate. Implementation and acceptance do not authorize commit, tag, GitHub Release, or npm publication.

## Candidate Scope

- Remove every built-in or generated default LLM provider, model, endpoint, profile, and credential assumption.
- Require an explicit user-owned external Workspace profile and successful live doctor for LLM-required operation.
- Preserve human-maintained `models.json` across Workspace initialization and Agent-host lifecycle operations.
- Synchronize the WorkBuddy expert, owned MCP entry, isolated npm runtime, and persistent Workspace binding.
- Return Registry, Organization Catalog, and immutable Bundle identifiers and digests for EvoPilot read-only consumption.

Deterministic non-LLM operations remain available while model readiness is incomplete. The Release never borrows an Agent host's conversation model and never publishes model credentials.
