# EvoPilot Harness 3.2.1

v3.2.1 hardens the Proposal Review Engine against production GLM response shapes while preserving strict evidence and human-approval boundaries.

## Fixed

- Source-derived project membership, product boundary, Advisor consistency, and multi-source coherence conclusions must cite valid Evidence Graph ids.
- Catalog overlap, Proposal structure, definition quality, evaluation sufficiency, and non-source findings may use empty `evidenceIds` instead of inventing citations.
- String-form definition-quality checks are deterministically normalized into structured report entries before validation.
- Review requests carry an explicit 8192-token structured-output budget.
- Missing or unknown source citations, incomplete source membership, invalid JSON, and exhausted bounded repair still block approval.

## Compatibility And Authority

This patch does not change Asset v3, Catalog, Registry, published Harness assets, the v2 compatibility surface, or the Guided Operator's human gates. GLM may review and recommend only; it still cannot approve, publish, execute source projects, mutate configuration, invent evidence, or override deterministic gates.

No external project, generated Proposal, or Review Report is added to the built-in Harness asset library.
