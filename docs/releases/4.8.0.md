# evopilot-harness 4.8.0

> Status: released. Published through GitHub Release and npm with Registry signatures and SLSA provenance.

## Scope

- Bounded `OntologyReasoningProfile/v1` modes: NONE, RDFS, OWL_RL, SWRL_SAFE, and qualified EXTERNAL_REASONER.
- Content-addressed semantic and graph indexes with cache, algorithm, snapshot, and asset bindings.
- Deterministic affected-subgraph calculation, selective re-reasoning, and incremental/full-recompute equivalence.
- JSON-LD, PROV-O, RDF, OWL, SHACL, multilingual term, and governed external-vocabulary projections.
- Federated read-only Pack discovery with independent Catalog provenance, permission, visibility, digest, and trust context.
- Immutable terminal ontology, index, reasoning-profile, HarnessProfile, HarnessComponent, and HarnessBundle closure for later read-only EvoPilot consumption.
- Complete v4.7.0 compatibility inheritance and no-regression requirements.

## Authority boundary

External vocabularies remain inactive evidence. External reasoners are qualified evidence providers and are not executed by Harness. Federated Catalogs do not share mutation or authority. Terminal closure publication, Target acceptance, Engine Release, and the later cross-product convergence E2E remain separate decisions.

## Exclusions

No general-purpose knowledge graph platform, executable Pack, unbounded OWL or SWRL reasoning, shared mutable global ontology, eventual authority, automatic external-vocabulary activation, live cross-organization authority or publication, cloud control plane, EvoPilot Runtime implementation, or completed cross-product E2E claim.
