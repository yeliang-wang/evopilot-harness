# EvoPilot Harness v1.2.0 Release Notes

EvoPilot Harness v1.2.0 adds the multi-Catalog Harness Registry. `evopilot-harness` can now publish and validate `harness-registry.yaml`, while keeping `CATALOG.md` as the only per-Catalog Harness entry index.

## Added

- `evopilot-harness registry publish` creates or updates `harness-registry.yaml`.
- `evopilot-harness registry validate` validates Registry schema, enabled Catalog roots, `CATALOG.md` blocks, and optional expected Catalog digests.
- Harness Hub snapshots include Registry status, enabled Catalog count, blockers, and Catalog references.
- Documentation now separates Registry, Catalog, and template contracts.

## Compatibility

- Compatible EvoPilot: `>=3.1.0` for Registry consumption.
- Compatible Catalog consumers without Registry support can still read `published/CATALOG.md` directly through legacy Catalog directory configuration.

## Validation

```bash
npm run check
npm run release:artifact
npm run verify:release-artifact
git diff --check
```

## Hand-Off To EvoPilot

```bash
node src/index.mjs catalog publish --source harnesses --out published --json
node src/index.mjs registry publish --catalog published --registry harness-registry.yaml --json
node src/index.mjs registry validate --registry harness-registry.yaml --json

EVOPILOT_HARNESS_REGISTRY_CONFIG=/path/to/evopilot-harness/harness-registry.yaml
```
