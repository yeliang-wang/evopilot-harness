# EvoPilot Harness 3.0.1

v3.0.1 is the production release of the v3 asset-factory baseline. It includes the complete v3.0.0 capability set and fixes migration rollback on case-sensitive Linux filesystems.

## Fixed

- Generate canonical lowercase migration journal ids for new v2-to-v3 migrations.
- Resolve rollback journals using the exact id returned by migration apply, preserving compatibility with earlier mixed-case ids.
- Reject migration ids that could escape the Workspace migration directory.
- Add cross-platform journal filename and path-traversal regression coverage.

## Included v3 Baseline

- Product-neutral `HarnessComponent`, `HarnessProfile`, and immutable `HarnessBundle` assets.
- Evidence Graph, Eligibility Gate, Ontology, BM25 retrieval, multi-factor scoring, novelty, risk policy, and cited decisions.
- Policy-governed GLM Advisor with evidence citations and no approval authority.
- Human-reviewed Proposal lifecycle, Evaluation Packs, signed Catalog/Registry support, migration, rollback, and Harness Hub v3.
- Frozen v2 compatibility commands and optional EvoPilot exports.
