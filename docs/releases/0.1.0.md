# evopilot-harness v0.1.0 Release Notes

`evopilot-harness v0.1.0` is the first independent Harness Catalog release for EvoPilot `v2.5.0` and later.

## What Changed

- Provides source Harness packs under `harnesses/`.
- Publishes a usable offline Catalog under `published/`.
- Emits `CATALOG.md` with a fenced `yaml evopilot-harness-catalog` block.
- Includes `database-product-harness@2.2.0`, `api-gateway-harness@2.2.0`, and `distributed-cache-harness@0.1.0`.
- Keeps language/runtime Harness baselines available for EvoPilot auto-match fallback.
- Validates domain Harness execution contracts, including structured required actions, evidence adapters, and release blockers.

## Compatibility

- Compatible EvoPilot: `>=2.5.0`.
- Catalog schema: `evopilot-harness-catalog`.
- Harness schema: `evopilot-harness-template/v1`.
- Node.js: 22 or later.

## Validation

```bash
npm test
npm run catalog:publish
npm run catalog:validate
```

## EvoPilot Consumption

```bash
evopilot harness catalog mount \
  --source /path/to/evopilot-harness/published \
  --json
```

EvoPilot dynamically reads the mounted Catalog and locks selected template/Catalog digests when generating project profiles.
