# EvoPilot Harness 2.0.0

EvoPilot Harness v2.0.0 promotes Harness production into a professional asset factory. The release keeps `template.yaml` compatible for EvoPilot consumption, while adding Harness Asset v2 envelopes, Source Profile v2, Auto-Match v2, unknown-source matching evaluation, and LLM Advisor replay gates.

## Added

- Added Harness Asset v2 (`apiVersion: evopilot.dev/v2`, `kind: HarnessAsset`) with metadata, template, match, execution, evidence, lifecycle, quality, relations, conditions, and provenance.
- Added `asset inspect` and `asset validate` for source packs and published Catalog directories.
- Added Catalog v2 fields: `assetApiVersion`, `assetKind`, `qualityReport`, `entries[].assetPath`, `entries[].assetDigest`, `entries[].qualityScore`, `entries[].qualityStatus`, and publication provenance.
- Added Source Profile v2 scanner evidence, scanner summary, runtime-log signals, sensitive-material signals, and uncertainty reasons.
- Added Auto-Match v2 decision context with candidate retrieval, conflicts, review gates, uncertainty, and decision evidence.
- Added `eval run` for unknown-source matching regression gates.
- Added `llm replay` for validating stored LLM Advisor responses without live model access.

## Changed

- `npm run check` now publishes and validates Catalog/Registry, validates Harness Assets, runs unknown-source evals, replays LLM Advisor cases, builds the Hub snapshot, checks docs links, and runs node tests.
- Published Catalog directories now contain both `template.yaml` and `asset.yaml` for each published Harness version.
- `asset validate --source published` supports the published `<harness-id>/<version>` directory shape.
- `detect`, `evolve`, and corpus planning now expose v2 matching metadata while preserving existing review and approval gates.
- Documentation now describes the `evopilot-harness` boundary as Harness production only. EvoPilot remains the project onboarding and goal-loop execution control plane and is not part of this release.

## Compatibility

- EvoPilot compatibility range remains `>=3.0.0` for the legacy `template.yaml` path in the Catalog.
- Harness Asset v2 is an additive publication envelope. EvoPilot consumers that only read `entries[].path` can continue to read templates; v2-aware consumers can read `entries[].assetPath`.
- `evopilot` and `evopilot-dashboard` are not released as part of this version.
