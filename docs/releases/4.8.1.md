## Scope

4.8.1 adds indexed semantic Catalog supply for the approved Runtime 6.3.0 and
Evolution Expert 2.3.0 convergence. Harness remains the producer; EvoPilot
consumes published immutable assets through read-only Registry/Catalog access.

- Publish, discover and validate `semantic-catalog-supply/v1` closures with
  immutable dependency generations, exact content digests and provenance.
- Preserve compare-and-swap and receipt recovery, append-only successor and
  rollback behavior, permissions and existing asset formats.
- Retain the 4.8.0 professional reasoning, interoperability and authority
  boundaries under fresh successor verification.
- Invalidate earlier model readiness when reinitialization fails for the same
  configuration, without changing the human-maintained model file or selecting
  a fallback provider.

See the [semantic Catalog implementation reference](../reference/semantic-catalog-implementation.md)
for source-level scope and the [Roadmap](../roadmap/ROADMAP.md) for the accepted
milestone. Local tests and this note are not installed-artifact acceptance.
