# EvoPilot Harness 4.0.0

Status: source tag only. GitHub CI failed before GitHub Release and GHCR publication because the no-listener test assumed `/usr/sbin/lsof`. Use v4.0.1.

## Added

- Portable Agent-neutral Digital Expert Core with deterministic Codex, WorkBuddy, Claude Code, MCP, and Generic Adapters.
- Local stdio MCP Harness Operation Server with version negotiation, typed tools, resources, health/capability reporting, graceful shutdown, and no default network listener.
- Exact Product, Expert, Core digest, Agent protocol, and Engine API initialization binding before any Workspace mutation.
- Persistent `AgentOperationSession` with atomic writes, SHA-256 integrity, Plan/Proposal/Review/approval/publication bindings, stable operation idempotency receipts, fail-closed interruption reconciliation, cross-Agent resume, cancellation, close, and owned-session cleanup.
- Direct structured Engine adapter; MCP does not run a child CLI or parse human terminal output.
- Independent Generic Agent Host conformance runner.

## Changed

- Digital Expert is the ordinary human entry. The v3 JSON CLI remains for CI, compatibility, and emergency diagnosis.
- The former Guided Operator Skill is a compatibility alias and no longer contains a second workflow or policy copy.
- Approval and publication are separate Session decisions. General continuation language cannot satisfy either gate.
- Maintenance Catalog/Ontology/Policy publication has its own digest-bound authorization after Plan confirmation; multi-Proposal publication remains resumable until every authorized Proposal is published.

## Preserved

- v3 Harness assets, Workspace state, Proposals, Catalog, Registry, feedback packages, and JSON CLI contracts.
- Engine authority for reasoning and Review.
- Static source ingestion with no source-project execution.
- Secret-free Session persistence and symlink-aware external Workspace write confinement.
- Independent Harness asset, Engine, EvoPilot, and Dashboard versions.

## Excluded

- Remote or multi-tenant MCP.
- Embedded conversational model or general Agent runtime.
- Automatic approval, publication, model configuration, or source execution.
- EvoPilot Goal Loop behavior.
- v4.1 comparative evidence and v4.2 professional asset learning.

See [v4 Acceptance](../operations/v4-acceptance.md) for candidate evidence.
