# EvoPilot Harness 4.1.2

> Status: released on 2026-08-21; available through [GitHub Release](https://github.com/yeliang-wang/evopilot-harness/releases/tag/v4.1.2) and [npm](https://www.npmjs.com/package/@evopilot/harness/v/4.1.2).

v4.1.2 is a documentation-system and release-drift maintenance patch for the unchanged v4.1 controlled comparative-evidence runtime. It aligns public, human, and Agent-facing entry points with the verified v4.1.1 publication state, then publishes those corrections as one immutable package version.

## Fixed

- Synchronized the root README, documentation index, `llms.txt`, Agent instructions, release ledger, npm distribution, troubleshooting, acceptance, and Asset Delta documentation.
- Corrected the legacy Guided Operator compatibility link so installed and source-checkout discovery resolves the generated Digital Expert Skill.
- Expanded the native Markdown link checker across root governance documents, Agent Skills, technical documentation, Harness definitions, and published Catalog documentation.
- Added deterministic tests that bind the package version to its current Release note, documentation index, npm commands, troubleshooting commands, and stale-release wording.
- Made npm package verification and installed-runtime smoke derive the expected version from package metadata, reducing future release-only edit drift.

## Compatibility And Boundaries

- Harness reasoning, matching, comparison, calibration, schemas, Digital Expert semantics, MCP contracts, CLI behavior, Harness Hub, Catalog, Registry, and user Harness assets are unchanged from v4.1.1.
- The public package remains `@evopilot/harness`, the CLI bin remains `evopilot-harness`, and npm publication remains OIDC Trusted Publishing with provenance.
- EvoPilot and evopilot-dashboard are unchanged.
- GHCR and remote deployment are not included in this release.
