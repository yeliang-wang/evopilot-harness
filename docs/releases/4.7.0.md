# evopilot-harness 4.7.0

> Status: released. Published through GitHub Release and npm with Registry signatures and SLSA provenance.

## Scope

- Declarative, independently versioned Domain, Product, Organization, Project Overlay, and Domain Harness Packs.
- Exact import, dependency, precedence, replacement, provenance, root, visibility, conflict, and digest closure.
- Explicit Draft, apply, Review, Approval, Publication, installation, activation, successor, rollback, and deprecation transitions.
- `ProjectOntologyProposal/v1`, immutable `ResolvedProjectOntologySnapshot/v1`, `ProjectOntologyArtifactSet/v1`, and `ProjectOntologySkill/v1`.
- Deterministic YAML, OWL, RDF Turtle, JSON-LD, bounded SWRL, and SHACL projections with explicit non-applicability.
- Inactive external semantic evidence and exact advisory certification records.
- Complete v4.6 compatibility inheritance and no-regression requirements.

## Exclusions

This release does not add executable marketplace plugins, automatic Pack trust or publication, a cloud marketplace, universal built-in vertical expertise, a general-purpose graph database, unbounded inference, automatic imported-vocabulary activation, incremental reasoning, federated discovery, or EvoPilot Runtime execution.
