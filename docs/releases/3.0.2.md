# EvoPilot Harness 3.0.2

v3.0.2 is a documentation and governance release for the v3 Harness asset-factory baseline. It keeps Engine behavior and all published Harness assets compatible with v3.0.1 while making the current architecture, lifecycle, ownership boundaries, and operating paths explicit for humans and AI agents.

## Added

- Apache License 2.0 and NOTICE files aligned with package metadata.
- Contributing, security, and code-of-conduct entry points.
- `llms.txt` for AI-agent documentation discovery.
- Developer guide covering source ownership, change flows, tests, generated outputs, and secret handling.
- Dedicated v2 compatibility architecture and migration guide.
- Release-note index and a verified Harness Hub v3 product screenshot.

## Changed

- Reorganized the root README as a concise product entry with Quick Start, asset model, reasoning, ownership, compatibility, and documentation routing.
- Rewrote the generic architecture and Harness lifecycle pages around the current v3 Component, Profile, immutable Bundle, Workspace, Proposal, Evaluation, Catalog, and Registry model.
- Routed legacy `detect`, `evolve`, source-pack, and v2 Catalog behavior through explicit compatibility pages.
- Clarified that Engine, Harness Asset, Ontology, Policy, Evaluation, Catalog, EvoPilot, and Dashboard versions evolve independently.
- Clarified the local-first release contract and that ECS is outside the default release chain.
- Removed external reference-project comparison language from current public documentation.
- Included root governance files, `llms.txt`, and the Harness Hub screenshot in verified source release archives.

## Compatibility

- No CLI, schema, algorithm, Hub runtime, or Harness asset behavior changes.
- v2 compatibility commands and migration remain available.
- Existing v3 Workspaces and immutable Bundles remain valid.
- No EvoPilot or Dashboard release is required by this documentation release.
