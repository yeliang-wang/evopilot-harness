# EvoPilot Harness 3.0.0

v3.0.0 changes `evopilot-harness` from a repository of EvoPilot-shaped templates with source matching into a user-owned, independently versioned Harness asset factory.

## Before And After

| Area | v2.1.0 | v3.0.0 |
|---|---|---|
| Product scope | Broad source classification and template generation. | Eligibility and evolution decisions for repeatable engineering Harness assets only. |
| Canonical asset | EvoPilot-compatible template plus v2 envelope. | Product-neutral Component, Profile, and immutable Bundle. |
| Mutable state | Repository-local data roots mixed with Engine content. | Read-only Engine plus `EVOPILOT_HARNESS_HOME` Workspace. |
| Domain knowledge | Significant role, regex, recommendation, and weight logic in CLI code. | Versioned Ontology and Policy Packs loaded by v3. |
| Matching | Structured heuristics and deterministic candidate scores. | Eligibility Gate, Evidence Graph, Ontology, BM25, seven-factor scoring, negative conflicts, novelty, risk policy, and cited decisions. |
| Unknown domain | Could become a generated Harness target. | Must become a reviewed Profile Proposal first. |
| LLM | Optional Advisor with domain-specific prompt examples. | Policy-required only for ambiguity/new Profiles, generic evidence-bound prompt, valid `evidenceId` citations, token/digest/replay record, no approval authority. |
| Quality | Section-presence checks and small fixed fixtures. | Formal JSON Schemas, immutable dependency digests, Evaluation Packs, adversarial tests, and explicit `INSUFFICIENT_EVAL_EVIDENCE`. |
| Publication | Harness template Catalog. | Signed asset Catalog, Registry-root validation, human approval, and optional control-plane exports. |
| Versioning | Engine and shipped Harnesses were closely associated. | Engine, asset, Ontology, Policy, Evaluation, and Catalog versions evolve independently. |

## Added

- `HarnessComponent`, `HarnessProfile`, and `HarnessBundle` canonical assets.
- `OntologyPack`, `MatchPolicyPack`, `AdvisorPolicyPack`, and `EvaluationPack` contracts.
- Formal JSON Schemas with AJV 2020 validation.
- Configurable Workspace under `EVOPILOT_HARNESS_HOME`.
- `produce` for local projects, project roots, GitHub, attachments, logs, historical Harnesses, notes, and controlled research.
- Redacted snapshots and Evidence Graphs with stable `evidenceId` values.
- Eligibility, BM25 retrieval, multi-factor scoring, negative conflicts, novelty, and deterministic review decisions.
- GLM Advisor evidence citations, token accounting, policy/version digests, replay records, and authority enforcement.
- Profile Proposal review, approval, Evaluation review, and immutable publication.
- Ed25519 Catalog and Registry signatures.
- Release provenance that distinguishes clean CI artifacts from dirty local preview archives without exposing raw working-tree paths.
- v2-to-v3 dry-run, apply, journal, and rollback.
- Harness Hub v3 assets, proposals, governance, evaluation, and LLM usage views.
- 13 v3 end-to-end tests plus the existing 20 v2 compatibility tests.

## Compatibility

- v2 commands remain available as a frozen compatibility layer.
- The existing nine v2 source packs are mechanically migrated into built-in v3 Profiles and Bundles.
- Original v2 templates are preserved as optional `exports/evopilot/template.yaml` projections.
- No EvoPilot or evopilot-dashboard change is included in this release.
