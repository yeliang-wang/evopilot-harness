# EvoPilot Harness 4.1.0

v4.1.0 adds controlled comparative evidence and policy calibration to the Agent-native Harness producer. Externally produced Baseline/Candidate results become immutable, replayable, uncertainty-aware evidence for Proposal and policy review without transferring execution, approval, publication, rollback, or policy-activation authority to the comparison system or an LLM.

## Added

- `HarnessComparisonEvidencePackage`, `HarnessComparisonReport`, `HarnessComparisonRescoreRecord`, `ComparisonPolicyPack`, `HarnessCalibrationCaseSet`, and `HarnessCalibrationReport` versioned schemas.
- Approval, redaction, expiry, provenance, digest, exact asset/Proposal, task, source snapshot, environment, model, toolchain, EvaluationPack, scorer, and metric binding validation.
- Deterministic paired scoring with repetitions, wins/losses/ties, missing observations, uncertainty, conflicts, safety blockers, context strata, limitations, and one bounded recommendation.
- Immutable, idempotent package intake and append-only scorer/policy-versioned rescoring that preserves accepted observations and prior reports.
- Matching and Proposal policy calibration over independently reviewed cases, including ranking, abstention, false upgrade, false new profile, regression, conflicts, and uncertainty.
- Proposal Review integration that separates expected effect from comparatively supported effect and rechecks the comparison snapshot before approval and publication.
- Atomic JSON CLI, Digital Expert, local stdio MCP, persistent Session, and Harness Hub support for comparison and calibration.
- `EVIDENCE_REVIEW_REQUIRED` plus exact Comparison/Calibration Report acknowledgement that records review only.
- Clean-tarball installed-package smoke that completes real Comparison and Calibration Sessions without a source checkout.

## Compatibility

- Existing v3 assets, Workspaces, Catalogs, Registries, Proposals, EvaluationPacks, feedback packages, JSON CLI automation, and v4 Agent operation remain compatible.
- Existing Sessions without `evidenceReports` are read and resumed with an empty compatibility collection; historical state is not bulk-rewritten.
- Legacy Proposals do not require comparative evidence unless a separately reviewed policy explicitly requires it for their risk class.
- EvoPilot and evopilot-dashboard are unchanged. The published Catalog/Registry consumer contract is unchanged.

## Boundaries

- v4.1.0 does not execute source projects, Baseline/Candidate Harnesses, Goal Loops, tests, deployments, benchmarks, or business commands.
- Comparison and calibration cannot approve or publish a Harness, activate policy, perform rollback, mutate Catalog assets, or train a model.
- LLM semantic advice cannot override deterministic schema, comparability, safety, uncertainty, conflict, digest, review, approval, or publication gates.
- The milestone does not implement v4.2 professional asset learning, unrestricted research, long-horizon learning, automatic domain expansion, or universal matching claims.
- GitHub Release, npm, optional GHCR, and any deployment remain separately authorized and independently verified publication layers.
