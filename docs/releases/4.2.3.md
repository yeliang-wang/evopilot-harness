# evopilot-harness 4.2.3

> Status: candidate

This candidate closes Harness-owned LLM initialization for installed third-party Agent hosts without importing host credentials or changing Engine authority.

## Candidate scope

- separates product installation from Harness LLM initialization readiness;
- exposes `NOT_CONFIGURED`, `CONFIGURED_UNVERIFIED`, and `CONFIGURED_AND_VERIFIED` through Workspace, bootstrap, and host-installer status;
- adds `llm v3-readiness`, `llm v3-initialize`, and the MCP `initialize_model_configuration` tool;
- performs configuration-only inspection followed by a minimal live doctor;
- stores only a mode-`0600`, secret-free Workspace verification receipt;
- invalidates readiness when the human-maintained model configuration changes;
- defaults later Advisor and Proposal Review operations to the verified Workspace configuration;
- preserves LLM-optional deterministic behavior and all existing human approval and publication gates.

The validated Target was separately authorized for commit, push, tag, GitHub Release, and npm publication. GHCR and deployment are not part of this release.
