# EvoPilot Harness 4.1.1

> Status: released on 2026-08-20 from commit `afc38f6426e793606f5dcb97eee9fd5679c413d9`; available through [GitHub Release](https://github.com/yeliang-wang/evopilot-harness/releases/tag/v4.1.1) and [npm](https://www.npmjs.com/package/@evopilot/harness/v/4.1.1).

v4.1.1 repairs the normal npm OIDC Trusted Publishing path for the unchanged v4.1 controlled comparative-evidence runtime. The v4.1.0 GitHub Release completed, but its npm workflow stopped before publication because setup-node's `registry-url` configuration injected a placeholder `NODE_AUTH_TOKEN` that the repository correctly rejected.

## Fixed

- Removed `registry-url` and kept `always-auth` absent from the normal `actions/setup-node` configuration so npm can obtain short-lived OIDC credentials through Trusted Publishing.
- Added an executable preflight before npm Registry commands that rejects every explicitly supplied `NODE_AUTH_TOKEN` without printing its value.
- Added parsed workflow and negative token-boundary tests proving that the normal path has no npm secret, token fallback, or setup-node auth injection.

## Preserved Controls

- GitHub permissions remain `contents: read` and `id-token: write`, with the protected `npm` Environment.
- Publication remains bound to the exact Git tag, package version, and stable or prerelease dist-tag.
- `npm publish --provenance`, Registry integrity, signatures, SLSA attestation, `npm audit signatures`, clean exact-version installation, Agent bootstrap, and `npx` verification remain mandatory.
- The one-time first-publication Bootstrap remains blocked after the public package exists and is not reused by this release.

## Compatibility And Boundaries

- Controlled comparison, calibration, Harness reasoning, schemas, Digital Expert workflows, MCP contracts, Hub behavior, and user Catalog assets are unchanged from v4.1.0.
- EvoPilot and evopilot-dashboard are unchanged.
- npm account, Trusted Publisher, GitHub Environment, identity, 2FA, secrets, and tokens remain external configuration and are not created or modified by this release.
- GitHub Release, npm publication, optional GHCR publication, and deployment remain separate, explicitly authorized actions.
