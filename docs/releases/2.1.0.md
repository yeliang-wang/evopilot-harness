# EvoPilot Harness 2.1.0

EvoPilot Harness v2.1.0 adds GitHub repository sources to Harness detection and evolution, then documents the full Harness operating model in a single OpenHands-style guide. It keeps the v2 template, Harness Asset, Catalog, and Registry contracts compatible.

## Added

- Added `--github-repo`, `--github-ref`, `--github-cache-root`, and `--github-depth` for GitHub repository or git remote source inputs.
- Added GitHub source coverage metadata: repository, input, upstream URL, ref, resolved commit, and local cache path.
- Added GitHub source support for:
  - `detect`
  - `evolve`
  - `evolution create`
  - Harness Hub lifecycle command suggestions
- Added credential rejection for HTTPS repository URLs that include username or password material.
- Added generated `definitionQuality` guidance to Harness drafts, focused on product boundary precision, match-policy specificity, evidence-contract completeness, domain execution action granularity, and reviewable negative signals.
- Added LLM Advisor definition-quality advice fields.
- Added [How Harness Works](../guides/how-harness-works.md), covering:
  - Harness source-pack and published-Catalog management
  - single-source and corpus evolution
  - existing-Harness upgrade versus new-Harness creation decisions
  - deterministic matching, Source Profile v2, Auto-Match v2, and optional LLM Advisor review
  - local project, source root, GitHub repository, attachment, production log, note, and goal inputs
  - `template.yaml`, Harness Asset v2, `CATALOG.md`, and `harness-registry.yaml` publication attributes
  - EvoPilot read-only consumption and `selectedHarness` evidence

## Changed

- Updated README and documentation indexes to route administrators and AI agents through the new operating-model guide before deeper CLI and reference pages.
- Updated CLI quickstart, workflow, command, testing, and source-to-harness docs for GitHub repository sources and definition-quality goals.
- Rebuilt the published Catalog and Registry metadata for the `v2.1.0` release.

## Compatibility

- EvoPilot compatibility remains `>=3.0.0`.
- `template.yaml`, Harness Asset v2, Catalog v2, and Registry v1 contracts remain compatible with `2.0.0`.
- EvoPilot and Dashboard are not released as part of this version.
