# evopilot-harness v4.2.1

> Status: candidate — implementation and acceptance only; not released.

v4.2.1 adds an extensible third-party Agent-host installation lifecycle. WorkBuddy is the first concrete adapter and registers a visible `EvoPilot Harness数字专家` through WorkBuddy's supported expert-manager scripts. The expert uses the packaged instruction Skill and exact-version local stdio MCP server; it does not require an evopilot-harness source checkout.

- `agent bootstrap` remains read-only.
- Mutating operations require an exact preview `planDigest`.
- Only owned integration is changed; unrelated configuration and the external Workspace are preserved.
- Managed state is backed up and unowned conflicts are rejected.
- WorkBuddy-specific registration stays behind a host-neutral lifecycle contract.
- Harness reasoning, review, approval, and publication authority do not move to the Agent.

Implementation acceptance does not authorize commit, push, tag, GitHub Release, or npm publication. Container publication and deployment are outside the supported distribution scope.
