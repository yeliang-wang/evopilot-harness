# Distributed Cache Harness

Domain Harness for self-developed distributed cache and key-value storage products. Redis and Memcached are compatibility references and differential oracles, not products EvoPilot should evolve in place of the owner's system.

## Execution Boundary

- Cache semantics: consistency, TTL, eviction, persistence, and protocol compatibility.
- Cluster behavior: sharding, slot migration, replica recovery, and failover.
- Evidence: protocol report, cluster topology, benchmark summary, runtime logs, and chaos/failover test output.
